Introduction

As drones become more common—whether for recreation, commercial use, or more serious threats—detecting, tracking, and classifying them accurately has become essential for airspace safety. From civilian airports to military zones, the ability to identify drones quickly can prevent disruption or danger. To support NATO's efforts to protect against the misuse of drones, this dashboard explores how various sensors perform in real-world tracking scenarios. Switch between different flight scenarios to compare sensor performance across various conditions.

The Data

The dataset includes timestamps, latitude and longitude (from radar sensors ALVIRA and ARCUS), and bearing, which represents the direction from the sensor to the signal source (as reported by RF sensors DIANA and VENUS). The data was provided by NATO as a set of comma-separated files, organized by drone and flight scenario. For better comparison, this analysis focuses on single-target tracking.

Radar / RF Sensors

Meet our four sensors: ALVIRA, ARCUS, DIANA, and VENUS. Despite their human names, these sensors have highly technical, even superhuman, capabilities:

  • ALVIRA — 2D radar providing range and bearing info. Located at 51.5213°N, 5.8586°E.
  • ARCUS — 3D radar capable of altitude differentiation. Located at 51.5215°N, 5.8706°E.
  • DIANA — RF direction-finding sensor with a 180° view. Located at 51.5191°N, 5.8580°E.
  • VENUS — RF direction-finding sensor with a 360° view. Located at 51.5193°N, 5.8579°E.

📶 Altitude Tracking

This chart shows each sensor's reported altitude over time compared to the Ground Truth (black line). Discontinuities or spikes may indicate lost tracking, sensor drift, or latency. Use this chart to validate the reliability of vertical position detection.

📉 Position Error Analysis

Displays how far off each sensor's reported position is from the Ground Truth, measured in meters. Lower error indicates better tracking performance. High error values may point to environmental interference or weak signal confidence.

🗺️ Multi-Sensor Flight Path Map

The map shows live tracking overlays from each sensor versus the Ground Truth flight path. Black represents the known trajectory; other colors represent sensor-reported tracks. Use this to compare spatial alignment and detect location offsets or tracking divergence.

Real-Time Performance Metrics

These metrics summarize how well each sensor is performing in terms of detection rate and error. Cards are color-coded: green for good, yellow for warning, and red for critical. Values update every 5 seconds to reflect the latest results.

📘 How to Use This Dashboard

  • Select Different Scenarios using the scenario buttons to compare sensor performance across various flight conditions.
  • Use the Timeline Slider to move through the mission in time. You can also use your keyboard:
    • ← / → to step through frames
    • Home to jump to the beginning
    • End to jump to the end
  • The Altitude Chart shows drone altitude from sensors vs ground-truth.
  • The Error Chart displays position error (in meters) over time.
  • The Flight Path Map maps all positions using real geolocation data.
  • Sensor Cards indicate real-time status per detection system.
  • Performance Metrics update every 5 seconds with sensor performance.
  • Sensor Filters allow you to show/hide specific sensors for focused analysis.

This dashboard dynamically visualizes multi-sensor fusion across different scenarios. Data updates in real time as you scrub through the timeline and switch between flight scenarios.
